# 真实功能接入台账

这是业务功能材料与接入状态的唯一记录位置，依据一期方案§10与路由契约§2、9。任务执行状态另见 TASKS.md，不在两处维护同一任务进度。

## 当前盘点事实

2026-10-10复核：《智驭版意图1.xlsx》已提供14项业务场景，当前26项模拟原子功能及六条文档Skill组合，尚无真实接口接入条目。场景资料与未来真实接口材料见智驭功能包；旧模板发布保留兼容。旧20项目录及新智驭目录均不计入真实接入数量。不能把文档示例、接口不同版本或重复用途算为不同真实功能。

DEC-001 与 INT-001 负责取得清单；收到第一批真实材料即可逐项记录，不等待全部齐备。未取得材料的真实已知功能可登记“待材料”，但不计入验收完成数。

## 每条真实条目的字段

| 字段组 | 必要内容 |
|---|---|
| 识别与责任 | 稳定功能ID、功能名称、业务域、所属空间、业务/接口负责人 |
| 权威资料 | API/Schema或登记位置、文档及修订/章节、接口协议和鉴权引用；仅保存安全位置，不保存秘密值 |
| 实体与动作映射 | 业务对象、动作、角色、关系、限制；输入输出、实体绑定、前置条件、成功规则及最终结果组件 |
| 功能封装与策划规则 | 直接调用时登记涵盖的接口/工作流及操作说明；组合功能登记介绍、固定直接子功能版本及Markdown Skill，文档说明适用目标、参数来源、条件、确认点与回答要求；本轮具体计划和最终映射由模型生成、后台校验并持久化，首版仅一层组合 |
| 执行边界 | 只读/副作用、确认要求、超时、重试、幂等、异步及未知结果处置 |
| 验证与发布 | 测试环境、真实契约测试证据、功能版本、AgentRelease/智能体成员关系、状态及阻塞 |
| 可追溯关联 | 需求ID、实施任务ID、相关评测切片与已知问题 |

## 状态与计数

沿用方案：待材料 → 解析中 → 待确认 → 待测试 → 可发布 → 已发布 → 已停用。推进状态需要对应材料/映射确认/真实测试/实际发布证据，不能仅依据生成文件或模拟返回。

正式验收只计入已经发布且有真实契约测试证据的不同业务功能，并核对**同一个验收智能体的发布快照同时包含全部至少20项**。停用功能不计数，接口多个版本不重复计数。至少选取相近功能、角色/动作差异、知识与事实查询、必填参数；异步按真实范围测试或记录不涉及理由。

选择两个子集智能体和领域扩展场景时遵循 DEC-009 最终决定。第21项由既有连接器支持时须证明用户自助完成且无业务特例代码，并按 TESTING.md 回归原20项的全量S1。

本文件是材料入口与接入治理规则，尚不是已完成的20项接入清单。
