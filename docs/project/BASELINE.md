## 一期工作基线

沿用 V2.1 陈述的目标：全部内网运行；在权限隔离空间自助加入至少 20 个真实不同业务功能；完成语义与动力映射；同一智能体同时启用至少 20 项；场景功能组合；独立平台管理前端与可 iframe 嵌入的统一智能体前端。

功能名称、接口 URL、示例 ID、JSON 字段样例、框架选型、准确率、样本量、时延和人员排期都不能直接当作真实环境事实。REQ 编号和验收映射见 [REQUIREMENTS.md](REQUIREMENTS.md)，接口细节仍以原契约为依据。

完整自主规划、复杂任务编排和全行场景覆盖不作为一期前提。M1 的少量功能贯通只是中间结果，不能替代 20 功能验收。

用户确认一期同时覆盖 HTTP/OpenAPI、Dify 和 HiAgent；旧会话固定创建时 AgentRelease，撤销独立生效；两个子集智能体及新增领域必须分别有证据。新增领域可与第21项合并演示，但不能省略原20项完整S1。

本地 Compose 使用 Docker PostgreSQL 17.6、分离的 owner/app 角色及明确开发模式。开发夹具与本地宿主不是正式业务资源；HiAgent 实例协议尚待提供，通用映射适配不等于某一版本已联调。配置和环境边界见 [本地运行手册](../operations/LOCAL_RUNBOOK.md)。
