# 智驭业务助手使用与接入说明

本目录依据《智驭版意图1.xlsx》实现14个业务场景，包含26项可复用直接功能和六条组合规则。所有客户、产品、政策、业绩与联系人均为模拟资料；R1–R3真实接入继续搁置。实施与验收状态只查[TASKS](TASKS.md)。

## 如何体验

本机入口：[直接聊天](http://127.0.0.1:5173/chat/5d019540-83ca-489f-bc38-441dc0a64db3)、[管理平台](http://127.0.0.1:5173/console/)、[示例宿主](http://127.0.0.1:5175)。本机当前发布v6固定32项功能（26个单项和6个组合）、六条文档Skill、`scope-v11`及DeepSeek V4.1 Flash非思考模型配置，数据库为0018；不同机器安装时使用其新生成的链接。新建会话使用当前发布，旧会话保留创建时版本。INT-035低成本模型回归执行25/40例，22通过、3失败、15未执行；该结果不是完整模型验收，详见[TASKS](TASKS.md#int-035-超级工作台真实数据评测与精简验证)及[评测记录](records/INT-035-real-data-evaluation.md)。

管理端在“智能体”中进入“智驭业务助手”，查看已选功能、模型、发布版本和试聊入口。用户端使用该应用自己的Chat链接，直接输入问题，无需选择模拟角色。当前新访客由服务端自动绑定默认演示身份（客户经理甲）；历史会话按原身份恢复，刷新不会改换角色或扩大数据范围。iframe和管理试聊同样不提供角色选择。

欢迎区只显示后管“对话界面”配置并发布的推荐问题，点击后填入输入框，确认内容后发送。全部14场景仍可直接用自然语言调用，例如：

- 单意图：“星澜科技的存款余额有多少”“查我2026年9月业绩完成情况”。
- 组合：“给星澜科技生成访前一页纸，包含画像及合作情况”“比较星航科创贷和远帆经营贷”。
- 单目标自主拆解：“查我名下科创贷款客户的代发人数”。
- 多意图自主规划：“查星澜科技存款余额，同时找外汇存款定价联络人”。
- 通用问答：“解释什么是现金流，用通俗语言”。
- 陪练：“启动星澜科技的AI陪练”，随后进行多轮交流；点击“结束陪练”生成反馈。
- 模拟写入：“给星澜科技创建代发服务回访任务，截止2026-10-20”。核对对象和参数后确认；随后可查询该任务。

默认演示身份可以访问星澜科技及两家同名远川制造。“远川制造”需要按授权候选消歧。客户经理乙和主管的模拟范围保留为内部权限验证数据，用户页面不配置身份；提示词不能变更权限。正式场景后续对接行内身份与权限管理，本轮不实现该对接。

## 回答与日志

智能体详情分为业务能力、对话界面、访问控制。添加能力在居中弹窗搜索和勾选，确认后修改草稿；取消不会改动已有选择。保存后检查三层结构，按对象查看动作和能力、展开组合流程查看固定依赖。运行限制为系统保护，不是可编辑参数。

顶部“版本历史”先查看固定功能版本，确认回退只改变新会话的默认发布，不覆盖草稿及旧会话；“分享与嵌入”提供链接、iframe及身份握手说明。访问控制集中渠道、用户和网站：公开Chat免登录，授权名单用于Key iframe和管理试聊；即时停用或撤销网站独立于草稿，发布不会自动解除。测试报告和变更记录在顶部“更多”中查看，试聊仍固定已发布版本。

用户端标明业务结果、模型回答、混合回答或模拟陪练。业务数据只能来自授权功能和登记资料；政策资料不足时明确说明，不用模型补造。报告与纪要是草稿，可查看和下载，不自动录入系统。金额与排名由确定性处理器计算。

后台运行日志按会话、轮次和阶段查看：实体识别及绑定、动作筛选、规则或模型计划、执行与结果。通用模型回答没有业务调用。恢复只读取既有结果，不重新执行业务；未知写入须核对，不能因界面刷新重发。

## 功能包与真实替换材料

权威定义位于`backend/src/intent_platform/zhiyu`，历史导出包为`output/INT-026/functional-packages.json`。每项原子功能含输入输出Schema、实体动作、处理器操作、例句、样例、状态语义、确认及幂等要求；场景与能力的数量不等同。

新功能配置按[本轮基线](../../方案/功能配置与文档Skill实施基线_2026-10-10.md)维护：选择业务对象和动作，再配置完整输入输出字段；顶部测试实际执行当前草稿，成功后才发布。输出案例只能从当前修订成功测试的获准结果保存，不能代替字段契约。

组合设置先查看已选子功能，点击“添加子功能”再搜索勾选，确认后才写入当前编辑草稿；取消不改变原选择。依赖保持固定发布版本，有新版本时显式更新。Skill说明可以使用查询汇总、对比分析、资料草稿、确认办理模板：先预览，再应用；已有内容须明确替换或追加，取消保留原文。模板辅助写规则，不代替业务检查；完成后仍需保存、实际测试及发布。

保存固定Skill文档版本需现有Skill发布权限。测试、发布可以由不同获准人员分工，发布仍检查测试作者当前权限、测试运行身份及来源登录会话和真实账本；另一发布者不能读取作者私有测试内容。测试身份已退出或过期时，重新登录后可能需要重新执行测试，同修订的历史成功不能代替当前有效证据。模拟识别引用来自本空间已发布定义，未发布草稿不能扩充服务目录；基础业务类型尚无识别服务时作为语义类型，不伪造授权绑定。摘要模型失败则展示已完成的获准结果，不重办业务。

新组合功能选择已发布的直接子功能，填写业务介绍与Skill文档。文档写清适用目标、参数来源、依赖、条件、失败和结果要求；发布固定文档及子功能版本。匹配后由模型生成本轮有限计划，校验后执行；不匹配时只在智能体显式选择的直接功能范围内自主规划。旧六条模板规则及历史会话保持原逻辑，不因新文档版本发布被改写。当前服务是否已切换及验证结果见TASKS。

用户最终答复统一使用Markdown，引用与文件保持授权。结构化输出仍是后端核对字段、传参和确定性计算的依据，不能让模型绕过契约返回未经批准的数据。

接真实接口时，请逐项提供业务及接口负责人、权威协议和字段说明、获准测试地址、凭据安全引用、管户与对象授权规则、成功及失败样例、调用限额、幂等与状态查询方式。政策/FAQ还需明确资料版本、来源地址及失效规则；文件需说明下载授权和保存期。模拟角色仅用于本应用模拟数据，不能当成真实对象授权。

## 安装、切换与恢复

开发环境的空间管理员使用`POST /api/v2/management/workspaces/{ws}/synthetic/zhiyu/install`，可指定已配置的`model_profile_id`。重复安装相同目录不会重复创建版本；已修改定义不会被静默覆盖。未配置模型只可做明确的工程机制检查，不能把固定结果当模型回答。

旧演示替换使用`backend/scripts/retire_demo_catalog.py`的一次性维护命令，不提供产品永久删除页面。清理前保存数据库备份并用`verify_backup_restore.py`验证恢复；维护窗口停止新请求与派发，重新生成精确清单，再按同一事务清理。账号、成员、Key、模型加密凭据与共享配置保留。

本机已按清单清理30项旧功能、12个旧助手及其880个会话；切换前备份保留于`.local/backups/intent-20261009-192331-487-INT026-cutover.dump`。恢复核验与清理结果在`output/INT-026/main-backup-verified.json`和`main-retirement-applied.json`，详细操作约束见[本地手册](../operations/LOCAL_RUNBOOK.md)。不要手工复用旧应用ID、旧票据或匿名恢复凭据。

恢复数据库和恢复代码分别执行。恢复备份后先保持入口关闭，按当前撤权状态重新验证账号和渠道；不得因恢复让旧应用票据、匿名恢复凭据或旧运行会话重新可用。新应用标识与旧链接不同，宿主后端须更新目标应用，不把旧访客历史自动接管到新应用。

验证报告区分功能正确性、实际模型路由、答案质量与耗时；当前目录不代表银行业务、硬件性能或真实宿主验收。
