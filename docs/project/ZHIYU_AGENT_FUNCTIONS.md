# 智驭助手功能清单

## 范围与口径

最新授权边界（2026-10-14）：平台统一校验登录身份、空间、应用和功能使用权；客户/账户等对象级授权由具体功能版本配置。新功能的`function`模式由功能或下游接口按业务规则判权，服务端可按显式请求头注入当前可信用户/空间标识；`none`模式表示该功能无需对象级授权。实体层只负责定位与绑定，不以模拟岗位或管户表替代功能权限。历史发布缺少此配置时沿用原行为。本地模拟结果不代表银行真实授权。

截至 2026-10-14，本机当前发布为「智驭业务助手 v6 / scope-v11」，固定包含 26 个单项功能和 6 个 Skill 组合。此清单根据已发布目录、组合定义与 Skill 文档整理；项目功能接入台账当前未登记真实接口接入项。

本目录为本地合成演示数据（fixture）：不访问真实银行接口或网络；客户、产品、政策、业绩和任务资料均不能当作真实业务事实或银行政策。唯一写操作是「创建模拟营销任务」，仅在明确确认后写入模拟任务。

输入字段名和类型来自功能 Schema；「必填/选填」按当前直接功能 Schema 标记。列表输出以 [] 表示，并列出每项字段。组合输出按其 Skill 规则保留对应步骤的完整获准返回字段。

命名说明：贷后概览的Skill原文称末步为“汇总贷后风险提示”；组合定义实际绑定的功能ID为 zhiyu.postloan.summary，功能目录名称为“汇总贷后管理事项”。表中保留Skill原文，并按组合绑定列出实际功能名。
