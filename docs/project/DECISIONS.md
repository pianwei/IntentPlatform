## 决策落地方式

上述DEC-005、008～011的决定来源为本任务中用户对落地计划的选择及“PLEASE IMPLEMENT THIS PLAN”实施指令。实施时保留原问题和来源；后续变更应记录新的决定及受影响范围。具体平台地址、鉴权密钥、硬件及业务API不由这些选择推导。

更新对应 DEC 条目，保留原问题、决策日期、实际决策人或授权来源、采用方案、考虑过的关键替代、理由/代价、受影响任务与文档、重新评估条件。重要技术取舍可按需另建 ADR 并在此链接，常规实现不新增文件。

待决策的建议不得直接改为“已确认”。需求变化先同步 REQ、任务、验证口径及范围，再实施依赖变更；不为了让当前失败通过而改低验收要求。
