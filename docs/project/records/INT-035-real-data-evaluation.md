日期：2026-10-13。该记录仅汇总本机忽略目录中的原始快照和逐例证据，不复制客户级字段或答案。

## 数据来源与边界

用户授权读取超级工作台源码并导出只读数据。本轮读取使用超级工作台项目当前开发配置的数据源，并在导出事务中设置只读；连接端的生产/测试来源无法独立核实。因此应称为“超级工作台来源数据回放”，不能声称是生产数据或真实银行接口验收。未启动源应用，未执行CRM写操作，也未改源项目或数据库。

在本地受限目录中脱敏映射的覆盖量：15个客户、97条标签关系、5条完整客户指标/代发/授信样本、295个产品、299条文档元数据（不含正文或URL）、8个营销任务及17条客户关联、5个客群及13条客户关联、5条拜访、若干提醒和10条客户经理业绩记录（没有目标值）。源导出仅含必要关联标识；未收集联系方式、地址、账号凭据或自由文本。没有与样本客户匹配的贷款记录；缺少可用的政策/FAQ正文、联系人详情、完整合作和营销反馈、贷后检查明细、通用待办和业绩目标。数据缺口限制了功能覆盖。

原始来源快照和逐例模型证据在Git忽略的`backend/evaluation_data/local/`，不得提交。该目录不适合作为共享交付物。

## 执行规模和结果

完整计划仍为384个场景：260个单功能、40个边界、30个多轮、30个Skill、12个自主规划及12个模型兜底。为控制DeepSeek成本，当时构建20个候选，其中18个来源业务数据候选、2个不依赖业务资料的通用兜底问法；最终11个唯一场景获得实际模型执行，累计41次模型请求尝试。按每个唯一场景的最终有效重跑结果计，8通过、3未通过；这不是26项功能的覆盖分数，也不代表完整验收。INT-026的106条合成结果仍为独立历史基线。

通过场景覆盖了客户资料/搜索、产品搜索/详情、客群查询、产品对比Skill、跨经理隔离拒绝和模型通用回答。跨经理案例的运行状态为拒绝，但因预期正是拒绝而判定测试通过。一次客户资料场景早期出现输出契约错误，之后独立冒烟成功，早期失败仍保留且原因未能确定。客群用例首跑的金标错误地统计了所有客群，修正为指定客群后通过；该首轮结果保留为测试夹具修正记录。

三项未通过为营销客户查询、单目标自主规划、多意图自主规划。可观测到三者均未能在实体授权预检阶段把模型提出的业务对象绑定为当前测试身份获准对象；没有产生业务调用，两个自主规划场景未进入计划执行。应先修复模型实体提及与授权对象解析，再决定是否继续调用付费模型。本轮不进一步重跑模型。

另有14项本地来源处理器/金标预检通过；固定已发布功能输出契约预检通过；两项均为零模型调用。没有观察到模型传输或额度错误。结果基于当前引擎和隔离回放，不能证明源系统端到端集成。
