## 后端产出与权限边界

后端新增空间元数据分页目录、带修订号的重命名、平台管理员分配空间管理员、归档与恢复，以及成员分页搜索和有效权限说明。旧接口保留。接口定义同步到[公共契约](../../../backend/CONTRACT.md)、[空间治理契约](../../../backend/GOVERNANCE_CONTRACT.md)及 [OpenAPI](../../../backend/openapi.json)。

| 能力 | 已实现边界 |
|---|---|
| 平台空间目录 | 平台管理员可读全空间元数据；平台资格本身不授予成员身份或空间业务数据权限。 |
| 名称与管理员 | 平台或当前空间管理员可重命名；修订不一致返回409。创建空间、分配或恢复管理员资格、归档及恢复仅平台管理员。 |
| 成员与权限 | 分页按账号或显示名搜索，展示账号与成员状态；有效权限区分角色、资源许可和执行时另验的对象授权。成员管理和有效权限查询要求实际空间管理员。 |
| 归档准入 | 公开配置、图标及嵌入策略SQL，匿名与Key身份签发、握手、换票、兑换、续期和恢复，运行读取、历史、事件/SSE、文件，管理测试、发布及接入任务均检查空间状态和适用访问代次。 |
| 管理历史 | 归档后实际获准空间管理员仍可从管理接口只读会话、运行、轨迹、审计及受授权文件；没有该空间角色的平台管理员仍只读元数据。 |
| 未发送工作 | 归档结束未发送调用及待补参、待确认工作；未完成接入失败，不得在恢复后提交新修订。 |
| 已发送事实 | 与准入、计划提交、结果提交及最终发送共用空间事务锁。已发送调用仍可记真实成功、失败或UNKNOWN；不推进依赖步骤、不再调用汇总模型、不发起新的对账外呼，也不重放业务写入。 |
| 恢复 | 访问代次不降低，旧空间运行会话、恢复凭据及待用票据不复活，已有资源撤权保留；用户须按当前权限重新进入。账号和Key不因单个空间归档而被全局停用，其他空间不受影响。 |

`0014_workspace_lifecycle` 增加空间状态、修订、归档元数据和访问代次，并为运行会话、握手、票据及接入任务保存空间代次。既有空间为 `active / revision=1 / access_epoch=0`，既有相关记录代次为0；不改写功能版本、发布快照或业务账本。迁移不提供破坏性自动降级；恢复须使用相容代码和受控备份，不能借回退复活已撤销权限。
