# INT-028 智能体配置与聊天首页简化

2026-10-10；等级 C；用户在十一项问题分析后授权修改。本轮仅变更前端及其测试、说明和稳定 Skills；沿用现有后端契约、模型、路由策略、发布和运行机制。R1–R3 继续搁置。

## 产出

- 配置页收敛为业务能力、对话界面、访问控制。顶部提供版本历史、分享与嵌入、试聊已发布版本、保存及发布；测试报告与变更记录放入更多操作。旧测试/发布页签链接仍可打开对应入口。
- 业务能力使用居中确认弹窗，提供搜索、分类、待选清单、依赖说明和批量选择。取消/Escape 不修改父草稿；仅已发布且未停用的能力可新增。宽屏能力与三层预览并排，窄屏单列。
- 三层按业务对象、动作/功能关系、组合规则展示。编译读取当前保存修订；规则及步骤说明读取固定发布版本，不借用最新草稿。隐藏日常运行策略选择；原策略、预算、旧发布兼容保留。运行限制为现有系统保护，首版不新增配置。
- 推荐问题逐项新增、删除、排序。Chat、iframe 和管理视觉预览共享发布配置驱动的欢迎组件；删除额外注入的十四场景菜单。业务能力仍可自然语言调用，未删处理器或业务接口。
- 渠道与授权集中访问控制。关闭当前开放渠道先确认并即时停止；启用草稿须发布，发布不会解除即时停用。成员授权即时生效，嵌入网站使用独立字段及准确 Origin 校验；既有即时撤销保留。
- 版本历史先读不可变功能名称和版本，再确认回退。读取失败、依赖详情缺失或存在未保存修改时阻止前端回退。回退只调用既有新会话发布指针接口；不改草稿、旧会话或紧急停用。
- 分享入口只提供有效链接、iframe 代码和握手说明，不再重复配置渠道。保存/发布业务成功与后续刷新失败分开反馈，避免误导用户重复提交。
