## 范围与限制

这是合成负载的工程诊断，不冻结银行性能阈值，也不证明真实模型、硬件、外围宿主、真实 Dify/HiAgent 实例或 20 项业务功能的容量。固定到达只有 8 次，吞吐和 P99 是该少量样本的最近秩统计量，不可外推。Markdown 解析在一秒内完成，在线健康读取只发生 3 次；慢解析不阻断 API 的故障注入证据仍以 INT-016 的后端定向测试为准。此记录只覆盖 INT-017 的负载子项，候选完整软件、升级、故障、恢复、离线与真实验收另行记录。
