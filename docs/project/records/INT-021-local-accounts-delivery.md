## 实现范围

- 后管使用审核后的浅色布局，主导航为智能体、功能库、运行日志；空间、模型和平台账号放入设置。空间显示名称，首页没有技术主键、角色串及常驻开发/权限说明。
- 功能编辑分为基本信息与执行、输入输出与映射、验证与发布；保存草稿和发布条件分开，参数有类型/必填/示例，低频 JSON 折叠。切换步骤保留输入，离开未保存页面提示，操作区固定。
- 运行日志采用会话列表、问答轮次和阶段详情。默认显示本轮真正的最终答复及表格/文件、状态、处理和等待耗时；顶部直接进入处理过程，按需读取中文三层事实。小屏使用详情页，返回保留筛选。未采集的历史交互或耗时不补造。
- 头像个人中心提供显示名、账号信息、中文权限、列表密度、改密、Key 和退出。平台管理员可创建账号、生成一次性密码设置凭证、重置、停用及查看操作记录。
- 默认及正式配置使用本地身份；密码按 Argon2id 保存。管理刷新凭据为 HttpOnly Cookie，访问 token 仅内存；旧 SSO/dev 登录在 local 模式拒绝，测试夹具限定 `env=test`。
- 公开 Chat 使用独立匿名主体和恢复凭据，不建立空间成员。iframe Key 绑定账号，宿主生成访客并保存平台 session 关联，换票、恢复、读取和发送前均检查当前权限。Key 不授予管理 API。
- 原三层路由、模拟功能、组合规则、账本、确认和恢复保留。管理预览通过父窗口签发限定应用的运行身份，不复用管理 token，也不接管匿名历史。

接口细节见[公共契约](../../../backend/CONTRACT.md)、[OpenAPI](../../../backend/openapi.json)和前端共享类型。新增迁移 `0012_local_identity`、`0013_conversation_logs`；管理日志使用受空间和管理员上限约束的只读投影，运行端归属检查不放宽。
