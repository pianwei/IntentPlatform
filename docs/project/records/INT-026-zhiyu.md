## 产出与范围

14个场景对应26项原子功能和六条组合，统一使用`zhiyu-v1@1`模拟目录。三层实体、动作、规则参与筛选与执行，模型只能组合当前发布且获准的能力。新发布固定提示策略，旧发布保持原快照。

模型问答使用独立的`MODEL_ANSWER`路径，通用回答不建立虚假计划或调用；具体业务、政策、产品问题仍经功能取数。混合回答分别标记业务事实与通用解释。陪练状态保存于会话，只使用获准模拟事实。

两名客户经理和主管由服务端绑定运行会话。匿名、用户Key、管理预览的身份边界继续保留；角色切换创建新的运行身份，Key宿主恢复通过服务端后继关联，并重验visitor、Key、账号、空间及应用授权。

迁移0015增加目录、模拟状态和角色/陪练字段；0016增加Key角色恢复关联。账户、密码、模型加密凭据和原发布不重写。用户最终结果投影排除陪练内部控制与事实字段。
