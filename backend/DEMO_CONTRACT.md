# 三层意图 Demo 契约

本契约只描述本地模拟 Demo。20 项演示功能使用隔离状态与 fixture-v2 连接器，不是 20 项真实银行功能，也不替代 M1–M3 的真实验收。真实功能仍登记在 `docs/project/FUNCTIONS.md`。

## 业务功能包

`intent_platform.demo.catalog.function_packages()` 是 20 项模拟功能的权威开发包。每包包含业务用途、实体和动作、有限入参与出参 Schema、正例和参数样例、只读/写入属性、错误与未知结果语义、幂等要求及模拟处理器操作代码。`domain_definition()` 定义客户、账户、交易、贷款、产品、持仓、工单与关系；`action_definitions()` 定义定位、查询、列出、统计、创建、冻结。`intent_platform.demo.engine` 在空间隔离的 `demo_states` 中执行筛选、关联、金额统计和状态变更，写操作按 `operation_id` 留存并可对账。模拟客户同名、账户冻结、空贷款、失败和未知结果可复现。模拟用户 `dev-reader` 仅获准客户 C001；这是本地对象授权夹具，不是正式对象授权来源。

## 发布与运行

开发管理员通过 `POST /api/v2/dev/demo/seed` 显式安装或核对演示包，发布同一智能体的 20 项功能、6 个动作和 5 个业务 Skill。可在 Console 的“业务动作与 Skills”页面操作。该端点在正式环境不可用。智能体“任务策划”页选择有限策划策略、已发布 Skill 与模型配置；保存草稿后发布，发布快照固定实体、动作、功能、Skill 和模型版本。无模型时仅可做标注清楚的规则链工程预览，无匹配 Skill 的问题会说明无法规划。

运行顺序为目标及对象识别、授权功能过滤、Skill 优先匹配、无 Skill 时模型提议、确定性校验、持久计划、逐步业务执行与结果汇总。模型只返回有限 JSON 计划，不能提供接口地址、代码、权限或未发布功能；非法计划最多修正一次，修正期间不派发调用。Demo 上限为 8 个逻辑步骤、5 个批量对象、20 次业务调用及 3 个并行调用。依赖结果引用仅能读取已发布输出 Schema 字段。写操作只能位于最后一步且须确认，已派发写操作 UNKNOWN 时先对账，不能自动重放。新消息、补参、改口或取消使用既有 revision/状态机边界。

5 个业务 Skill 是客户资金概览、账户收支分析、客户贷款概览、异常账户核查、客户业务全景，模板在 `intent_platform.demo.skills`。模型动态规划用于无匹配规则的组合任务；未配置可访问模型时该分支只能作桩测试。当前开发环境另有 DeepSeek 官网模型＋模拟业务的实测记录，见 [INT-018 DeepSeek 验证](../docs/project/records/INT-018-deepseek-validation.md)。新发布使用 `planner-v3`：只有触发词匹配的已发布 Skill 可被选用；模型对用户直接给出的多个标识分别建步骤，结果数组索引用点分路径；精确命中获准能力名称却误判域外时至多修正一次。旧会话继续固定原发布的 `planner-v1` 或 `planner-v2`，不改写发布快照。
开发规则链使用获准业务结果生成可读摘要；资金概览明确列示各账户与合计，账户/客户列表在用户端按行显示。旧会话已生成的历史答复按原记录恢复，不改写为新文案。

管理接口在 `/api/v2/management/workspaces/{ws}` 下提供 `/actions`、`/business-skills`、`/model-profiles` 与 `/runs/{run_id}/trace`。模型配置支持 OpenAI 兼容协议、明确名称和版本、思考模式、服务端加密凭据、连接及结构化输出测试。开发模式显式开启后，ModelPort 可调用 DeepSeek 官网精确 Chat Completions 地址；非思考请求发送 `thinking.type=disabled`。公网运行请求仅允许本 Demo 的完整 20 项模拟功能发布快照，业务连接器不获得公网例外；正式环境仍须使用获准内网模型。运行 API 继续使用消息、问题、确认与恢复协议。用户端的 Run/Event/History/SSE/耗时采用服务端白名单投影，只给步骤名称、获准展示的输入输出、状态和真实耗时；管理三层轨迹单独保存，仅空间管理员可读。技术标识用于防重放与恢复，不在页面展示。旧发布沿原路由策略读取，不改写历史快照。

## 开发演示问题

- `查询 C001 的所有账户余额，给我做资金概览`：客户 → 账户 → 逐账户余额。
- `张晨的所有账户余额，给我做资金概览`：同名客户暂停选择。
- `对 A001 做收支分析`：暂停补充起止日期；金额由确定性处理器计算。
- `查询 C001 的贷款概览`：合同、余额、还款和逾期。
- `查询 C001 的客户业务全景`：资料、账户、贷款与持仓。
- `对 A002 做异常账户核查，客户 C001，原因：演示状态复核`：先查状态，确认后创建模拟工单；拒绝确认零写入。
- `比较 T001 交易和 A001 账户状态`：无 Skill 时需已配置模型；固定规则预览不会冒充模型规划。

20 项各有 5 条开发正例，输入错误与模拟失败/未知边界另测；这些是开发夹具数据，不是封存金标。本轮官网模型只对每功能抽取 1 条、另测 10 条复合问题，不能代替全部开发问法或正式评测。银行内网模型、真实身份、接口、宿主和硬件到位后，应按项目 TESTING 与真实功能台账重新验证。
