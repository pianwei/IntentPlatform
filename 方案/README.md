总体方案是评审主文，契约设计是研发展开依据。明确基线为：**全部在银行内网运行；用户在权限隔离空间自助加入至少 20 个真实功能；至少一个智能体同时启用全部 20 项；平台管理前端与智能体运行前端分别交付，智能体必须具有可 iframe 嵌入的统一界面。**

文中的接口、数据结构、阶段安排、准确率和延迟均为建议设计，尚未实现或通过真实模型与硬件验证。完成方案不等于完成产品验收。
