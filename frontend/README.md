# 意图中台双前端

`console/` 为中文管理控制台，`agent-web/` 为统一智能体独立页与 iframe 页；两者各自生成 Vite 构建产物。共享类型与客户端在 `shared/`。React 18、TypeScript、Vite 7、React Router 7、Radix 与 assistant-ui 均在 `package.json` 精确声明，依赖树由 `package-lock.json` 固定。

## INT-023 创建和显示

- 智能体、功能、模型新建使用居中弹窗。功能在同一会话中完成三步，可展开工作页而不丢步骤、输入、测试参数或当前修订验证。直接打开资源链接使用工作页；步骤和页签写入URL，完整草稿及凭据不写浏览器历史或存储。
- 从智能体补建功能/模型后返回原输入。功能必须发布后才自动添加；仅保存的功能草稿不成为可执行能力。模型保存与测试各自反馈，已保存配置的测试重试不新建版本。
- 个人中心支持标准/较大/大字号（100%/112.5%/125%）和独立密度。聊天顶部显示偏好按浏览器和应用保存；禁用存储时本页面仍可调整。恢复默认只重置字号。
- 新会话先在本地开始，首次发送才创建服务端会话；历史隐藏无问答的空记录。刷新恢复已有业务不重发。未发送输入只在内存中保存，不承诺整页刷新后保留。
- 试聊明确使用已发布版本；草稿未发布修改不进入试聊。日志刷新保持轮次与阅读位置，先看最终答复，再按需查看阶段与业务明细。

## INT-029 功能配置与文档规则

当前功能编辑以[功能配置与文档Skill基线](../方案/功能配置与文档Skill实施基线_2026-10-10.md)为准；实施、验证和本地服务是否更新只查[TASKS](../docs/project/TASKS.md)。

- 直接功能使用业务对象、动作和标识参数表达业务映射。编译器、HTTP协议、解析器及历史版本不再作为普通用户的选择项；服务端固定当前支持策略，历史发布继续按原版本运行。
- 输入与输出使用字段表配置类型、必填、说明及示例，支持有界对象和列表。测试表单按相同Schema生成。改名或删除字段时必须处理引用，不能留下指向不存在字段的传输映射或实体绑定。
- 顶部保存、测试、发布分别反馈。测试先保存当前修订，再实际执行；发布必须取得同一执行修订的成功证据。失败、超时或未知结果不能作为通过，刷新和重试优先恢复原测试。
- 成功测试的获准结果可保存为输出案例。案例帮助理解字段，不替代输出Schema，也不改变业务执行定义；禁止把原始连接器响应直接保存为案例。
- 组合功能维护介绍、已发布的直接子功能和Markdown业务Skill。规则描述适用目标、参数来源、依赖、条件、确认及结果要求；不手工编写固定步骤JSON。模型依据发布时固定的文档和依赖生成本轮计划，后端校验后执行。旧模板只作历史兼容，不因查看页面而升级或修改。
- 用户最终答复使用安全Markdown；内部结构化结果仍用于校验、计算和传参。引用、授权文件及补参、选择、确认交互继续独立显示，管理诊断不进入用户答复。

组合编辑默认只显示已选功能；添加使用同一编辑容器的可搜索选择视图，暂存后确认，不嵌套另一套编辑弹窗。Skill提供四类Markdown说明模板及编辑/预览，已有文档不能静默覆盖；模板不触发自动保存、执行测试、发布或模型调用。局部交互证据与本地Web状态查INT-030，原INT-029质量项独立保留。

## 运行

默认交付方式是项目根目录执行 `./scripts/dev.ps1 up`，通过同一网关访问：

- 管理平台：`http://127.0.0.1:5173/console/`
- 已发布应用：`/chat/{public_id}`
- 嵌入应用：`/embed/{public_id}`
- 本地Key宿主样例：项目根 `examples/iframe_host.py`，默认 `http://127.0.0.1:5175`；旧dev-host只保留作历史夹具

两份前端制品独立构建，由同一站点共同托管；用户不需要面对两个端口。`console` 构建基址为 `/console/`，Agent Web 为 `/runtime/`，深层聊天路由由网关回退到同一 Agent HTML。API 使用同源 `/api/v2/`，字段以 `../backend/CONTRACT.md` 的 Application v2 为准。

源码组件调试需要 Node.js 20.19+ 或 22.12+（当前容器22.16），在本目录运行 `npm ci`、`npm run dev:console`、`npm run dev:agent`。Vite 内部端口 5173/5174 仅为开发工具，不能代替统一网关交付。其 `/api` 和 `/health` 代理默认指向 `http://127.0.0.1:8000`，可通过 `INTENT_API_PROXY` 指定容器 API。

本次主机 npm HTTPS 连接失败后，在 Docker `node:22.16.0-alpine` 中完成依赖安装和检查。当前 `node_modules` 含 Linux 原生依赖，不能当作 Windows Vite 安装使用。通过根目录 Compose 启动，或在该容器挂载本目录运行 npm 命令；切换平台应通过该平台的 `npm ci` 重建依赖。

## 本地联调路径

1. 默认local身份，使用已初始化或由平台管理员创建的本地账号登录；首次设置/重置使用管理员安全提供的一次性设置凭证。平台管理员ID来自服务器配置，界面不能自提权。
2. 头像菜单打开个人资料、密度偏好、账号ID、角色权限、密码及集成Key；只有平台管理员可建号/重置/停用。既有演示数据直接使用，不重新开启开发登录；模拟数据不计真实20功能。
3. 功能库按“基本信息与执行→输入输出与映射→验证与发布”编辑。必填参数、类型和样例就近提示；测试保存当前修订后实际执行，测试成功才允许发布。真实探测需获准环境，写探测另需允许副作用；高级JSON也不能扩大目标/凭据权限。
4. 智能体默认进入业务能力，选择功能与模型，按对象查看三层关联及编译结果。添加功能使用居中双栏弹窗，暂存勾选、确认后应用；创建功能或模型后返回智能体保留输入。顶部保存、试聊、发布始终可达；“对话界面”单独配置外观，外观预览不执行。居中“试聊”使用独立应用运行身份，调用真实已发布业务，关闭即退出该预览身份。
5. 顶部“更多”查看测试报告及变更记录；不再单设测试页，三层策略用顶部已发布版本试聊及完整开发集检查。功能测试顺序保存草稿、核对必要来源审查并实际执行；不隐式发布。测试结果限定当前执行修订，修改参数或执行配置后必须重新测试。发布、撤权和回滚需核对具体影响。
6. 顶部“分享与嵌入”打开 `/chat/{public_id}`，匿名访客只使用该应用及自己的会话；刷新凭专用恢复secret取得新的内存token。local会话固定创建时release；迁移前旧身份会话仅管理只读，不能自动续接。
7. 用[宿主后端样例](../examples/iframe_host.py)及其同目录HTML/JS联调：Key只配置在宿主服务器，服务器生成visitor并保存平台返回sid。应用需先发布准确宿主Origin，父子消息校验Origin/source/nonce；退出先由宿主后端撤销平台session。服务器配置见[运行手册](../docs/operations/LOCAL_RUNBOOK.md)。

智能体列表以空间内唯一名称识别对象，界面隐藏技术主键但保留内部引用。运行日志以conversation分页/筛选，摘要标题允许重复；选择一轮先查看输入、最终输出、状态和耗时，再展开阶段。历史未留存的补参原文不推造，新补参/确认来自验证后保存的交互记录；管理只读权限不改变访客runtime权限。

## 运行与安全边界

所有应用的欢迎区只显示后管逐项配置并发布的推荐问题，Chat、iframe和草稿视觉预览复用同一欢迎组件。点击问题只填入输入框，不创建会话或提交业务；不强制显示14场景菜单，全部业务仍可通过自然语言调用。Chat、iframe与管理试聊不显示模拟角色选择或身份配置；新访客由服务端自动绑定默认演示身份。匿名恢复凭据和定位仍按应用及既有模拟身份隔离，旧会话恢复不重置角色，普通访问token仍只在内存；iframe由宿主后端维持visitor关联，宿主不采信浏览器自报的session。内部角色测试接口保留兼容，正式行内权限接入留待后续。

回答来源显示“业务结果”“模型回答”“模拟陪练”或“业务结果与解释”；不暴露内部规划诊断。陪练按钮根据服务端practice_active显示，点击“结束陪练并查看反馈”发送一条普通会话消息，复用幂等、取消和恢复协议，不自动重发旧业务。

- 访问token只在客户端内存并通过Authorization发送；不写URL或浏览器持久存储。Console刷新凭HttpOnly、SameSite=Strict的auth路径Cookie取得新token，密码/Key/设置凭证不长期保存。
- iframe 依 `document.referrer` 的实际 Origin 申请握手；无可信来源不登录。父子消息验证精确 Origin、窗口 source、协议、智能体和 nonce；从不用 `*` 传票据。
- sessionStorage定位ID不构成授权。匿名Chat另外在localStorage按public_id保存专用recovery_secret与session ID；服务端仅存摘要，不接受裸ID或跨来源恢复。iframe不读取匿名凭据，session以可信宿主后端绑定为准。恢复读取历史快照和cursor后的事件，不重发消息；退出清除对应恢复信息并请求服务器撤销。
- 旧问题、旧确认和另一请求的交互禁用，服务端仍是最终授权与状态裁决者。已派发的业务不能被前端取消按钮宣称撤回。
- 最终答复使用有限 Markdown（标题、列表、表格、代码与安全链接）；HTML 不执行、图片不自动加载、链接仅允许无凭据的 HTTP(S)。授权文件和必要交互使用独立组件。文件只使用服务端 file ID，通过带当前运行身份的 API 读取后下载；不会导航至模型返回的任意下载地址。引用内容保持服务端原文，未定义结构不虚构来源。

## 已知界限

当前是本地工程基线，身份统一为local；不含真实银行功能清单、银行账号/对象授权审批、真实模型金标评测或正式外围宿主验收。OpenAPI JSON/YAML 导入由服务端有限解析器处理单文档内部引用，支持 GET/POST、标量 path/query/header 和平坦 JSON body；不支持项显示诊断并禁止选择，不抓取外部引用。v2 显式位置映射支持 query 与 body 同时存在，原 v1 不自动改写。复杂定义可在 JSON 映射中显式编辑，最终由后端编译器验证。Dify 与 HiAgent 接入需真实的服务端目标授权、凭据引用、版本及协议映射；未具备时显示验证错误。

外观预览不调用业务 API；管理试聊独立调用已发布版本。复制的 iframe 代码只加载界面，必须配套实现宿主后端换票、CSRF 防护和退出撤销。界面同时提供可复制握手 JavaScript，并标明宿主端点需要自行实现。未复制 Dify 主项目代码或引入其后端。

发布与回滚操作只调用当前配置的本地 API；本任务未向任何生产环境发布。开发入口、接口代理、宿主 CSP 与正式身份接入必须按真实部署条件配置。

## 保留能力与历史契约（不作为独立主导航）

以下保留原能力与兼容约束：领域映射归属功能及编译预览，来源资料归属功能附件，评测归属智能体测试，治理配置归属空间或服务端，不提供聚合旧页面的高级入口。

### 领域与评测归档

历史领域维护能力保留数据与接口兼容，不作为本轮普通功能编辑入口。新编辑使用业务对象与动作，服务端解析并固定已发布的领域及可信解析器；不再要求用户挑选 v1/v2 或解析器版本。旧发布不自动升级。409 冲突保留输入，JSON与表单共用一份草稿；无效JSON会阻止保存。解析器缺失属于服务端配置依赖，不提供地址或密钥输入。

运行问题显示服务端问题种类、字段名称和单位；实体/历史选择只提交 opaque option_id，名称描述仍由服务端解析授权。浏览器不转换单位。运行来源只展示后端非秘密绑定摘要。

“评测诊断”页下的“评测结构归档查看”在本地读取冻结格式 trial.json，显示版本、资源声明、全部分母、逐功能、S2/S3 与缺口。下载保留原始字节；格式化展示不用于评分。文件不上传、不入库、不调用业务，不自动作为验收。首次导入只检查可展示结构，不能代替后端严格数据模型校验或真实性核验；20 MB 以上归档使用离线工具查看。

新增定向测试：`npm test -- tests/domain-function.test.tsx tests/semantic-question.test.tsx tests/evaluation-archive.test.tsx`。归档测试可设置 `INTENT_EVALUATION_SAMPLE` 指向只读的既有 PostgreSQL fixture trial.json（必须有 2 个未观测安全步骤），以额外验证真实接口产出的格式及字节保留；默认不依赖本机输出目录。纯前端测试不替代真实模型、资源或浏览器验收。

### 来源资料与接入向导

“来源文档”支持上传新文档、追加修订、选择旧修订、查看抽取原文和章节。追加修订提交目录最新 expected_revision，409 时保留文件选择。原始文件下载仅在 original_available 时提供，通过管理身份读取固定修订；历史文本不会伪装成原文件。

功能目录 → 接入新功能 → “从 OpenAPI 文档接入”：选择来源修订并解析，查看诊断，选择支持的操作，再生成待审查草稿。操作不会调用业务接口。“HTTP 参数位置映射”允许编辑 v2 的 path/query/header/body 映射；重名跨位置保持独立，同位置冲突不会覆盖原字段。

“来源候选、冲突与审查”读取完整 API 事实与人工引用。引用固定文档/修订/章节/逐字摘录；候选解释需人工填写 JSON，不自动变成业务事实。定义与引用一次只编辑一类：定义未保存时可查看来源但不能修改，引用未保存或来源请求进行中时冻结定义编辑，可先保存引用或还原引用修改。保存完整引用列表会增加功能修订。确认理由只确认已保存当前值，任何定义或来源变化都需重新审查。未保存映射/引用、未处理审查及过期修订阻止验证发布；离开编辑工作页或切换空间后，迟到响应不会重新打开旧编辑器或覆盖新输入。

导入功能的验证需要已授权环境中的成功与预期 FAILED 两组参数探测；两组 WRITE 探测均需勾选允许写入效果。HTTP2 可显式选择契约约定的业务失败码（400/404/409/422，默认空），并保留必须发送空 JSON body 的约定；不把401/403、5xx或超时当作业务失败。界面传当前 revision、failure_arguments 和 allow_effects，不根据按钮点击宣称通过。字段结构、成功条件、状态/结果路径和有限前置条件仍在高级 JSON 中配置。定向回归：`npm test -- tests/source-import.test.tsx tests/domain-function.test.tsx`。

新功能使用服务端当前HTTP传输契约，不提供降级选择。旧HTTP版本只保留发布和测试夹具兼容；高级JSON不能绕过新作者规则。HTTP映射缺组、格式错误或参数引用失效时保留原文并阻断发布，修复后恢复编辑。归档的 sanitization 仅作为来源声明展示：已知秘密/线协议字段处理不代表未知秘密已检查，旧归档未提供范围时明确显示未提供。

### 可信引用的兼容约束

“空间治理”展示服务端获准的身份集成、实体解析器和凭据引用，不提供地址、密钥或新增信任源输入。空间管理员可编辑服务器名册中的成员、收紧运行限额、按运行标识查询分次尝试的耗时；维护者及发布者只能查看引用目录。自身成员不可修改，角色受服务端上限约束，已被服务端撤销授权的成员只读。409 保留选择或输入；显式重新读取最新设置后，核对新修订和上限再保存。刷新占用只更新查询时的占用快照，保留限额草稿。缺失或 null 的指标显示“未观测”，真实 0 保留为零；这些记录不作为容量、模型或硬件验收。

智能体“访问控制”中选择获准身份集成，随草稿发布；已发布列表和即时撤销独立显示。旧响应未提供选择字段时保存其他配置仍省略该字段，不臆造默认配置。旧版发布明确提示兼容规则，目录候选不等于该应用已实际使用。即时撤销对已有会话生效，发布和回滚不恢复；它只更新撤销状态，不替换未保存草稿或悄悄采用另一个修订。撤销的引用可从草稿移除，不能重新勾选。非 fixture 接入仅标明连接器类型，不代表真实业务验收；已选但停用或缺失的功能保持可见并可移除。

功能编辑的凭据下拉只显示与连接器类型匹配的获准引用；目录为空或未提供时明确说明配置依赖，不填假值。旧引用不在目录时保留原草稿并提示，最终可用性和全部权限由服务端验证。高级 JSON 不绕过服务端信任校验。

INT013治理行为的当前回归：`npm test -- tests/governance.test.tsx`。local目录由本地账号提供，旧SSO名册不是当前授权源；正式宿主、真实对象授权、连接器凭据及容量仍需实际环境联调，本地UI和fixture不代替该验收。

## 双端资源路由与空间层级

Console 采用窄导航与独立工作页，React Router 管理 `/spaces/{space}/agents/{agent}`、`functions/{function}`、`runs/{conversation}`、`settings/members/{member}`。平台目录为 `/platform/spaces/{space}`，账号为 `/platform/accounts`。刷新深链、前进后退和列表过滤均保留位置；跨空间返回使用各自上下文。复杂编辑不放入伪全屏弹窗。

空间选择器显示名称、最近访问及搜索；短任务用居中 Radix Dialog，多项选择/角色编辑用锚定 Popover，行操作用 Dropdown。Escape 关闭、焦点返回、键盘选择、窄屏和减少动态效果均在公共组件处理。菜单点击打开，悬停仅补充说明。

空间目录只返回元数据，不授予空间业务权限。空间详情分基本设置和成员；角色编辑保持多角色与原成员状态，查看有效权限追溯到资源。建号并加入失败时保留新账号并继续加入，不能重复建号。归档页只保留设置与获准管理员历史查询；恢复后需建立新运行会话，旧访客/Key会话不复活。

聊天历史可搜索、按日期分组和收起；输入草稿仅在当前浏览器页面内按会话保存。按run聚合一组回答，状态原位更新，不给每个事件另发一条消息。补参/选择/确认归属对应回答；失效交互只留摘要。复制、表格放大与返回最新均不重执行业务；没有通用“重新生成”。管理、匿名、Key及预览历史独立。

主要视觉参考 Linear Peek、Vercel Dashboard、Notion Members 与 Langfuse Sessions；本轮组件自行实现，没有复制其品牌资产或未授权源码。Radix、React Router 等依赖许可随安装包保留。当前验证与制品见 [INT-022任务](../docs/project/TASKS.md)。
